# Entrega Desafío RGB

Descubrí que una imagen digital puede representarse completamente mediante datos RGB y la posición de cada píxel. Me di cuenta al reconstruir el avatar desde el archivo CSV y comprobar que el resultado coincidía con la imagen original. Lo que más me costó al principio fue entender la relación entre los números y la imagen. Aprendí que una tabla de datos puede contener toda la información necesaria para reconstruir una imagen digital.
